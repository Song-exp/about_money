## 부록: 수치 재현 방법

모든 수치는 `data/app.db`를 읽기 전용(`mode=ro`)으로 열어 센 값이다. 예:

```sql
select source_platform, status, count(*) from scholarships group by 1, 2;
select source_type, count(*), sum(lat is not null) from local_benefit_merchants group by 1;
select coalesce(issuer,'-'), card_type, count(*), sum(image_url is not null) from cards group by 1, 2;
```
